# Recase

**Turn e-waste laptops into useful things** — bartop arcades (Batocera), digital photo frames, car headrest monitors, and kiosks — organized by laptop model.

Live site: **https://fordcrews.github.io/recase/**

## What’s here

| Path | Purpose |
|------|---------|
| `index.html` | App shell |
| `css/site.css` | Mobile-friendly styles |
| `js/app.js` | Loads JSON and renders Models / Projects / Links |
| `data/catalog.json` | All model specs, guides, and citations |
| `CONTRIBUTING.md` | How to add a model or guide via PR |

Starter models (Ford’s pile):

- Dell Inspiron 1545
- Dell Latitude D830
- Dell Inspiron 15 5579 2-in-1 (service tag **77CX4L2**)

Specs are cited from Dell manuals and panel datasheets. Gaps are marked **unknown** — look up your service tag and the sticker on the back of the LCD before you buy a controller board.

## Safety

Laptop batteries can fire if punctured, crushed, or shorted. Every project guide in the catalog includes battery and electrical warnings. When in doubt, remove the pack and recycle it properly before you cut or drill.
